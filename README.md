# RoleMI

> 先看懂岗位，再决定怎么投。

RoleMI 是一款运行在浏览器侧边栏中的求职决策助手。它把分散的职位信息、岗位分析、简历匹配和投递准备整理成一条连续流程，帮助你更快回答三个问题：这个岗位真正需要什么、我和它差在哪里、下一步应该怎么准备。

RoleMI 不替你海投，也不靠一个缺少依据的匹配分数替你做决定。它更关注招聘要求背后的实际工作、你已经拥有的真实经历，以及经历与要求之间可以解释的联系和边界。

## 你可以用 RoleMI 做什么

### 看懂岗位

从冗长的职位描述中整理岗位本质、核心要求、隐含要求和理想候选人，并把“沟通能力强”“业务理解深入”等抽象表达转化为更具体的工作问题。

### 看清差距

结合你的简历，将结果区分为直接匹配、可迁移能力和关键缺口。每项判断尽量回到岗位要求和真实经历，不把“相关”直接写成“具备”。

### 知道怎么准备

围绕目标岗位生成简历修改建议和沟通开场白。建议只帮助你更准确地表达已有经历，不鼓励虚构项目、技能或结果。

### 管理求职机会

把感兴趣的职位保存到岗位池，进行搜索、收藏和状态管理，并按需导出全部岗位或收藏岗位的 Excel 文件。

## 核心流程

```text
收集岗位 → 理解岗位 → 上传简历 → 判断匹配 → 优化表达 → 准备沟通
```

1. 在招聘网站打开职位，点击“提取当前岗位”；其他来源的职位可以手动粘贴。
2. 在岗位池中查看职位信息，并按需生成岗位深度分析。
3. 上传 PDF 或 DOCX 简历。上传不会自动开始匹配，是否分析由你决定。
4. 开始匹配后，查看直接匹配、可迁移能力和关键缺口。
5. 根据结果生成简历修改建议或沟通开场白。
6. 收藏重点岗位，或导出岗位列表进行后续管理。

## 当前支持

- 自动提取：BOSS 直聘、智联招聘、猎聘。
- 手动添加：其他招聘网站、邮件、聊天记录或其他文字来源。
- 简历格式：PDF、DOCX。
- 岗位管理：搜索、收藏、详情查看、重复识别和 Excel 导出。
- AI 能力：岗位理解、简历理解、人岗匹配、简历修改建议、沟通开场白。
- 浏览器形态：基于 Chromium 的浏览器侧边栏扩展。

暂不提供自动投递、招聘账号自动操作、面试日历或 ATS 管理。RoleMI 的目标是帮助你做出更有依据的投递决策，而不是替你控制招聘平台。

## 使用提示

- 自动提取前，请等待网页完整显示岗位标题和职位描述。
- 页面处于安全验证、登录失效、职位暂停或加载状态时，RoleMI 不会保存不完整内容。
- 首次安装或升级后，浏览器可能询问 BOSS 直聘、智联招聘和猎聘的网站访问权限；这些权限用于你主动点击“提取当前岗位”时读取当前职位页。
- 手动添加的岗位描述最多 2000 字；简历提取文本最多 4000 字。
- AI 分析结果可能受到职位描述质量、简历排版和模型能力影响，重要信息请回到招聘页面和原始简历核对。

## 数据与隐私

岗位、简历和分析结果主要保存在当前浏览器中。只有在你主动使用 AI 功能时，完成该功能所需的岗位信息、简历内容或派生上下文才会发送到当前选择的模型服务。

RoleMI 默认使用托管服务；你也可以配置兼容 Responses API 的自定义服务。自定义 API Key 仅保留在当前浏览器会话中，恢复默认服务会清除自定义配置。

匿名使用统计不保存岗位描述、简历正文或完整 AI 请求与响应。提交反馈时，只有你主动选择关联岗位，相关岗位描述和已经生成的分析结果才会随反馈发送；简历原文和附件不会作为反馈内容上传。

## 产品原则

- **先理解，再比较**：先明确岗位和候选人的真实信息，再判断是否匹配。
- **事实优先**：结论应当能回到职位描述或简历经历。
- **区分相关与具备**：允许解释能力迁移，但不掩盖真实缺口。
- **用户主动触发**：匹配、建议和沟通内容由用户决定何时生成。
- **结果可核对**：AI 提供辅助判断，不代表招聘方结论，也不保证面试或录用。
