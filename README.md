# RoleMI

RoleMI 是一款求职辅助浏览器插件：先看懂岗位，再决定怎么投。它帮你把招聘页面里的岗位信息收起来、看明白，再结合自己的简历判断是否值得投、应该怎么准备。

很多职位描述写得长，却不一定把真正的要求说清楚。RoleMI 想解决的不是“替你海投”，而是让每一次投递更有依据。

## 产品亮点

### 看懂岗位

从职位描述中梳理岗位本质、核心要求、隐含要求和理想候选人，并把抽象能力翻译成实际工作中需要处理的问题，减少只看职位名称和关键词带来的误判。

### 看清差距

结合你的简历，区分已经具备的能力、可以迁移的经验和仍需补足的关键缺口。结论会说明依据，不把“相关”直接说成“会”。

### 知道怎么投

根据岗位和真实经历整理简历修改建议与沟通草稿。RoleMI 不代替你编造经历，而是帮你把已有经验表达得更准确；生成沟通草稿时会持续显示正在整理的重点，不让页面停在一条静态提示上。

### 管理感兴趣的机会

岗位可以集中保存在岗位池中，支持搜索、收藏和导出。全部岗位与收藏岗位会分别生成清晰命名的 Excel，是否分析过、是否收藏过也能一眼看到。

## 使用说明

1. 在 BOSS 直聘、智联招聘或猎聘打开一个岗位，展开完整职位描述。
2. 打开 RoleMI，点击“提取当前岗位”。如果网页无法识别，也可以手动粘贴职位描述。
3. 在岗位池中打开岗位，先查看详情，再按需进行岗位分析。
4. 需要判断匹配度时，上传 PDF 或 DOCX 简历。上传后不会自动开始匹配，由你确认后手动开始。
5. 根据分析结果查看简历修改建议，或生成沟通草稿。后台生成修改建议时，可以继续展开并阅读匹配依据，完成后不会收起当前内容。
6. 对重点岗位添加收藏，需要整理时导出岗位或收藏列表。

RoleMI 默认使用自身服务。如果你有兼容 Responses API 的模型服务，也可以在“服务设置”中填写 API 地址、模型名称和 API Key。恢复默认服务后，自定义配置会被清除。

## 产品边界

- 自动提取目前支持 BOSS 直聘、智联招聘和猎聘。其他网站或非网页渠道可以使用“手动添加岗位”。
- 网页必须已经显示完整的岗位标题和职位描述。遇到页面仍在加载、安全验证、登录失效或职位下线时，RoleMI 不会保存不完整内容。
- 首次安装或升级后若浏览器询问网站访问权限，请允许 RoleMI 访问三个已支持的招聘网站；权限仅用于用户点击“提取当前岗位”时读取当前职位页。
- Edge 侧边栏未直接返回当前标签网址时，RoleMI 会在已获授权的页面内只读取当前网址并完成同一白名单校验，不读取其他网站。
- 手动添加的职位描述最多 2000 字。简历支持 PDF 和 DOCX，提取文本最多 4000 字。
- 匹配与修改建议来自岗位内容和你提供的简历，只适合作为求职准备参考，不代表招聘方判断，也不保证获得面试或录用。
- 自动分析可能受到职位描述质量、简历排版和模型能力影响。重要信息请回到招聘页面和原始简历核对。
- 岗位、简历和分析结果保存在当前浏览器中。使用分析功能时，完成任务所需的内容会发送到当前选择的模型服务。
- 自定义模型服务仅支持 Responses API。API Key 只保留在当前浏览器会话中；会话结束或密钥丢失后需要重新填写。


## 商城发布

商城发布使用独立 production build：源码默认连接本地后端；商城包必须通过 `ROLEMI_BACKEND_URL=https://... npm run build:store` 生成，构建会移除 localhost 并仅声明生产后端 Origin。
